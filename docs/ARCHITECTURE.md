# Architecture

OrbitGuard AI uses React 19 and Three.js for its single-page interface, satellite.js for SGP4 and coordinate transforms, and an Express server with Vite middleware in development. There is no database. The object catalog is held in process memory and cached in a small JSON file. By default it is under the OS temporary directory; set `ORBITGUARD_CACHE_DIR` to a mounted persistent path when the host's temporary storage is ephemeral. Without a persistent mount, successful data and provider retry metadata do not reliably survive host restarts or redeploys. The browser requests the catalog through the server API.

`src/services/celestrakService.ts` retrieves one documented GP catalog-number query (`CATNR=40697`, Sentinel-2A) plus three catalogued-debris groups (`cosmos-2251-debris`, `iridium-33-debris`, `fengyun-1c-debris`) from `https://celestrak.org`. Accepted records retain original OMM, source, NORAD ID, provider classification, UTC-normalized element epoch, and download timestamp. The verified snapshot under `data/snapshots/` contains 1 payload and 2,675 debris records; it is loaded only as historical data when offline mode is enabled. The previous unverified 15-record bundle remains removed. Current, historical, and synthetic records are kept separate. Offline mode makes no provider requests and retains the isolated synthetic educational scenario. In-flight retrievals are coalesced, successful groups are cached for the provider update interval, and `refresh=true` does not override per-group or refusal cooldowns. Refusal bodies and an allowlist of diagnostic headers are retained while cookie and authorization headers are excluded. `Retry-After` can extend the refusal period. `ORBITGUARD_CELESTRAK_REFUSAL_UNTIL` carries a known refusal expiry across restarts. Group epoch ranges are recomputed from retained OMM-backed objects to avoid stale timezone-shifted cache summaries.

`src/services/orbitalEngine.ts` initializes TLE or OMM records, propagates them with SGP4, searches synchronized states, computes Euclidean separation and relative speed, and builds chart points. `EarthViewer.tsx` transforms TEME positions to Earth-fixed coordinates at the same UTC simulation instant before rendering. Module state and selection are owned by `App.tsx`.

Main API routes are `/api/health`, `/api/objects` (add `?refresh=true` to request refresh of eligible groups without bypassing provider cooldowns), `/api/objects/:norad_id`, `/api/positions`, `/api/encounters/analyze`, `/api/data/status`, and `/api/validation` (also `/api/validation/run`).

`POST /api/ai/explain` accepts catalog object IDs and a time window, recomputes the encounter server-side, then returns a deterministic explanation or optional Gemini wording. Gemini is enabled only when `GEMINI_API_KEY` is configured and `ORBITGUARD_DISABLE_GEMINI` is not `true`; it cannot supply or alter the SGP4 measurements.
